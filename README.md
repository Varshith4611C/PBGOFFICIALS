> **PBG Officials** is a high-performance multi-platform digital hub delivering modern anime streaming, manga reading, live television, real-time community chat, browser-based games, and interactive digital experiences.

---

## 🚀 Platforms & Features

- 🎬 **PBG Anime**: Comprehensive anime streaming catalog with episode lists, multi-source playback, and instant search.
- 📖 **PBG Manga**: Responsive digital manga reader with chapter navigation and high-resolution viewing.
- 📺 **PBG TV**: Live online streaming platform for curated television broadcasts and media.
- 💬 **PBG ChatBox**: Low-latency, real-time community chat powered by WebSockets (`Socket.IO`).
- 🎮 **PBG Games**: Interactive in-browser web games including Business Board, trivia, and multiplayer challenges.
- 🛡️ **Full Legal & Privacy Suite**: Dedicated [Terms of Service](https://pbgofficials.dev/terms-of-service.html), [Privacy Policy](https://pbgofficials.dev/privacy-policy.html), [Cookie Policy](https://pbgofficials.dev/cookie-policy.html), and [DMCA Takedown Policy](https://pbgofficials.dev/dmca.html).

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Glassmorphic Design System), Modern JavaScript (ES6+), Font Awesome 6, Google Fonts (*Space Grotesk*, *Inter*)
- **Backend**: Node.js, Express.js 5
- **Real-Time Communication**: Socket.IO
- **Data & APIs**: `@consumet/extensions`, Axios, Cheerio, `@distube/ytdl-core`

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Varshith4611C/PBGOFFICIALS.git
   cd PBGOFFICIALS
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env` (if present) and configure your port:
   ```bash
   PORT=3000
   ```

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Or for standard execution:
   ```bash
   npm start
   ```

5. **Open in Browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)
